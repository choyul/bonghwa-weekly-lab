# 장터 구글 시트 규격

사이트는 이 시트를 **웹에 게시(Publish to the web)** 로 연 CSV 두 장만 읽는다.
컬럼 이름은 아래와 **글자 하나까지 똑같아야** 한다. 순서는 달라도 된다.

## 탭 A — `장터_판매`

| 컬럼명 | 타입 | 설명 |
|---|---|---|
| `id` | 문자 | 고유값. 예: `20260830-01` |
| `등록일` | 날짜 | `YYYY-MM-DD` |
| `품목` | 문자 | 예: 붉은 아오리 낙과 |
| `설명` | 문자 | 판매자가 쓴 원문. **가공하지 말고 그대로 출력** |
| `규격` | 문자 | 예: 4.25kg 상자 |
| `가격` | 숫자 | 원 단위 정수 |
| `수량` | 숫자 | 총 판매 가능 수량 |
| `판매자표시명` | 문자 | 실명 또는 농장명 |
| `대리게시` | 문자 | `Y`/`N` |
| `수령장소` | 문자 | 예: 농민회 사무실 |
| `수령일` | 날짜 | `YYYY-MM-DD` |
| `수령시각` | 문자 | 예: `17:30` |
| `마감일시` | 문자 | `YYYY-MM-DD HH:mm` |
| `주문링크` | URL | 구글 폼 링크 |
| `원글링크` | URL | 네이버 밴드 게시글 링크(없을 수 있음) |
| `노출` | 문자 | `Y`/`N`. `N`이면 목록에서 제외 |
| `상태` | 문자 | `수확예정` / `판매중` / `마감` / `종료` |

## 탭 B — `장터_주문집계`

| 컬럼명 | 타입 | 설명 |
|---|---|---|
| `id` | 문자 | 탭 A의 `id`와 대응 |
| `주문수량합계` | 숫자 | 시트 수식으로 자동 계산된 값 |

## 잔여 수량

    잔여수량 = 탭A.수량 − 탭B.주문수량합계

- 탭 B에 그 `id`가 없으면 주문 0으로 본다.
- 잔여수량이 0 이하이거나 `상태`가 `마감`이면 마감으로 처리한다.
- **마감일시가 지났으면 `상태` 값과 관계없이 마감**으로 보여 준다.

## 절대 넣지 않는 것

게시된 CSV는 **주소만 알면 누구나 열 수 있다.** 다음은 게시 대상 탭에 넣지 않는다.

- 판매자 계좌번호
- 판매자 전화번호
- 구매자 이름·연락처·주소
- 수령 장소의 상세 주소 (건물명까지만)

구매자는 **구글 폼 제출 완료 화면과 자동 회신 메일**로만 계좌와 자세한 안내를 받는다.

실수로 적어 넣더라도, 사이트는 `설명`·`품목`·`규격`·`판매자표시명`·`수령장소` 칸에서
전화번호나 계좌로 보이는 값을 찾으면 **그 칸을 화면에 내지 않고** 브라우저 콘솔에
경고만 남긴다. 어디까지나 실수 방어용이므로, 애초에 넣지 않는 것이 원칙이다.
