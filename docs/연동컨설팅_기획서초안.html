  1. 처리 시간(건당 6분 / 1분)은 항목별 예상치를 더한 값입니다. 농정축산과 담당자에게 실제 소요를 한 번 물어 두면 숫자의 무게가 달라집니다.
  2. 봉화군의 연간 농업 보조사업 신청 건수를 넣으면 4장의 "20건"이 실제 규모가 됩니다.
  3. 행정정보 공동이용으로 이미 확인 가능한 항목과 Open API로만 되는 항목의 경계를 농관원에 한 번 확인해 두면, 8장 1번 문("소관") 이야기가 더 정확해집니다.
  4. 개인정보 관련 표현은 군 개인정보 보호 담당과 한 번 맞춰 보시는 편이 안전합니다.

이 발표가 딛고 있는 자료

  • 농림축산식품부 — 농업경영체 등록확인서, 행정정보 공동이용 대상 추가 (2022. 8. 8. 보도자료). 8월 1일 시행, 행안부 「공동이용 대상 행정정보 현황」 고시. 원문
  • 농림사업정보시스템(AGRIX) — 농업경영정보DB Open API 안내. 지자체 대상 15종, 이용 절차 신청·심의·협약·지원·사후관리. 원문
  • 국립농산물품질관리원 — 농업경영체 등록 제도 안내. 원문
  • 봉화군 · 오늘의 봉화 테스트본 — 주간업무계획서에서 뽑은 보조사업 427건, 담당자 접수 처리 화면(apply-desk.html)이 센 처리 시간과 불일치 건수.

한 장으로 줄여야 한다면

6장(기술 준비 완료) + 7장(제도 준비 완료) + 8장(그런데 막힌 문)을 한 장에 세 칸으로 놓고, 마지막에 10장의 요청 세 줄만 붙입니다. 4장·5장의 숫자는 말로 하고 화면은 8장에 씁니다 — 이 발표에서 설득이 일어나는 자리는 시간이 줄었다는 대목이 아니라, 다섯 개의 문이 보이는 대목입니다.
