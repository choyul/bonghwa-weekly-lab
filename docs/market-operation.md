# 장터 운영 안내 (담당자용)

## 1. 시트를 웹에 게시하기 (처음 한 번)

1. 구글 시트에서 탭 이름을 `장터_판매`, `장터_주문집계` 로 만든다.
   컬럼 이름은 `docs/market-sheet-spec.md` 와 글자 하나까지 같아야 한다.
2. 메뉴에서 **파일 → 공유 → 웹에 게시** 를 연다.
3. **링크** 탭에서 왼쪽 칸은 `장터_판매`, 오른쪽 칸은 **쉼표로 구분된 값(.csv)** 을 고른다.
4. **게시** 를 누르고 나온 주소를 복사한다.
5. 같은 방법으로 `장터_주문집계` 주소도 복사한다.
6. `market-config.js` 를 열어 아래처럼 붙여넣고, `dev` 를 `false` 로 바꾼다.

       window.MARKET_CONFIG = {
         dev: false,
         sellCsv: '(장터_판매 CSV 주소)',
         orderCsv: '(장터_주문집계 CSV 주소)',
         ...
       };

7. 저장하고 올리면 끝이다.

> 게시 주소는 **누구나 열 수 있다.** 계좌·전화번호는 절대 이 탭에 넣지 않는다.

## 2. 새 판매글 올리기

1. 밴드나 전화로 들어온 글을 **담당자가 직접 확인**한다.
   (사이트는 밴드를 자동으로 긁어오지 않는다. 등재는 반드시 사람이 한다.)
2. 팔 수 있는 것인지 본다.
   - 직접 기른 **농산물 원물만** 된다.
   - 고춧가루·즙·효소·장류 같은 **가공식품, 주류, 영업신고 없는 달걀은 안 된다.**
3. `장터_판매` 탭에 한 줄을 더한다.
   - `id` 는 `등록일-순번` 으로 짓는다. 예: `20260830-01`
   - `설명` 은 판매자가 쓴 그대로 넣는다. 다듬지 않는다.
   - `상태` 는 수확 전이면 `수확예정`, 지금 팔면 `판매중`
   - `노출` 은 `Y`
4. 주문용 구글 폼을 만들고 그 주소를 `주문링크` 에 넣는다.
   폼의 **제출 완료 화면과 자동 회신 메일**에 계좌와 수령 안내를 적는다.
   (사이트에는 계좌를 두지 않는다.)
5. 최대 5분 뒤 사이트에 뜬다. 바로 보려면 브라우저를 새로고침한다.

## 3. 마감 처리

셋 중 아무거나 하면 마감으로 바뀐다.

- `마감일시` 가 지나면 **저절로** 마감이 된다. 손댈 것 없다.
- 주문이 다 차면(`주문수량합계` ≥ `수량`) 저절로 마감이 된다.
- 급히 멈춰야 하면 `상태` 를 `마감` 으로 바꾼다.

수령까지 끝났으면 `상태` 를 `종료` 로 바꾼다. 지난 기록에 남는다.

목록에서 아예 감추려면 `노출` 을 `N` 으로 바꾼다.

## 4. 시험해 보기

`market-config.js` 의 `dev` 를 `true` 로 두면 `data/sample_market.csv` 로 화면을 볼 수 있다.
파일을 건드리지 않고 그때만 보려면 주소 뒤에 **`?marketdev=1`** 을 붙인다.

로컬에서 열려면 저장소 폴더에서

    python3 -m http.server 8080

를 띄우고 `http://localhost:8080/#market` 으로 들어간다.

## 5. 화면 주소

| 화면 | 주소 |
|---|---|
| 장터 목록 | `#market` |
| 장터 상세 | `#market/<id>` |
| 지난 기록 | `#market/archive` |

깃허브 페이지는 정적 호스팅이라 `/market` 같은 경로를 서버가 받아 줄 수 없어
`#` 뒤에 붙이는 방식을 쓴다. 링크를 그대로 복사해 보내도 그 화면이 열린다.
