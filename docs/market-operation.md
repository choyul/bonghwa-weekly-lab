# 장터 운영 안내 (담당자용)

장터는 이제 **구글 시트가 아니라 서버(D1)** 에 있습니다.
주민이 직접 올리고 고쳐야 하는데, 시트는 주민이 쓸 수가 없어서입니다.

담당자가 하는 일은 두 가지뿐입니다.

1. **판매자 등록 신청을 받으면 전화를 한 번 걸어 확인하고 승인**한다
2. 그분의 **첫 글 한 건만** 보고 승인한다 (그 뒤 글은 저절로 올라갑니다)

승인 화면 주소: **`market-admin.html`** — 열람 코드는 보조사업 화면과 같습니다.

---

## 1. 왜 '사람'을 승인하는가

글마다 검수하면 농가 20곳이 한 해 10건씩만 올려도 **200번**을 봐야 합니다.
사람에 걸면 **20번의 통화**로 끝나고, 사고가 나면 글을 하나씩 지울 것 없이
그 판매자를 **한 번 정지**시키면 올라와 있던 글이 전부 내려갑니다.

## 2. 판매자 등록 신청이 들어오면

`market-admin.html` → **[판매자 신청]** 탭에 뜹니다.
휴대폰 번호를 누르면 바로 전화가 걸립니다. 세 가지만 여쭙습니다.

- 봉화에 사시는 게 맞습니까
- 파실 것을 **직접 기르셨습니까**
- 못 파는 것(가공식품·고춧가루·즙·장류, 술, 영업신고 없는 달걀)을 아십니까

통화한 내용을 메모 칸에 적고 **[승인]** 을 누릅니다.
그 순간부터 그분 휴대폰의 장터 화면에 "판매자 등록됨" 이 뜹니다.

> **반려** 는 안 될 사유가 분명할 때만 씁니다. 반려 사유도 메모에 적어 두십시오.
> 나중에 다시 물으실 때 근거가 됩니다.

## 3. 첫 글 승인

**[올라온 글]** 탭에서 봅니다. 보실 것은 두 가지입니다.

- **팔아도 되는 것인가** — 직접 기른 농산물 원물인가
- **개인정보가 적혀 있지 않은가** — 전화번호·계좌가 설명에 들어가면
  서버가 **승인을 막습니다.** 그때는 판매자에게 전화해 지우게 하십시오.

승인하면 그 판매자는 **'첫 글 검수 끝남'** 이 되고, 다음 글부터는 바로 올라갑니다.

## 4. 마감·주문 수량

- `마감일시` 가 지나면 **저절로** 마감이 됩니다. 손댈 것 없습니다.
- 주문이 다 차도(주문 수량 ≥ 수량) 저절로 마감이 됩니다.
- 구글 폼으로 들어온 주문 수를 **[주문 수량]** 칸에 넣고 [저장] 하시면 남은 수량이 줄어듭니다.
- 급히 멈춰야 하면 **[마감]**, 아예 안 보이게 하려면 **[숨김]** 입니다.

## 5. 사고가 났을 때

| 상황 | 하실 일 |
|---|---|
| 글 한 건이 문제 | 그 글 **[숨김]** |
| 그 사람이 문제 | 판매자 **[정지]** — 올라와 있던 글이 **한꺼번에** 내려갑니다 |
| 아주 지워야 함 | 글 **[삭제]** (되돌릴 수 없습니다) |

> 정지를 풀어도(**[승인]**) 내려간 글은 저절로 올라오지 않습니다.
> 올릴 글만 골라 다시 **[승인]** 하십시오.

## 6. 수정키를 잃어버렸다는 전화가 오면

판매자가 휴대폰을 바꾸면 판매자번호와 수정키가 필요합니다.
잃어버리셨으면 **[수정키 재발급]** 을 누르고, 나온 값을 **전화로 불러** 드리십시오.
누른 순간 예전 키는 못 쓰게 됩니다. 본인이 맞는지 확인한 뒤에만 누르십시오.

## 7. 개인정보

- 판매자의 **실명과 휴대폰 번호**는 서버에 저장되고 **이 화면에서만** 보입니다.
  장터 화면(`index.html`)에는 어떤 경우에도 나가지 않습니다.
- 화면을 남에게 보이거나 찍어 보내지 마십시오.
- **판매를 그만둔 지 3개월이 지난 분의 연락처는 지웁니다.** 아래 명령을 씁니다.

      cd lab-server
      npx wrangler d1 execute bonghwa-lab --remote --command \
        "UPDATE seller SET phone='', name='' WHERE state IN ('반려','정지') AND at < date('now','-3 months')"

## 8. 시트에 있던 자료 옮기기 (처음 한 번)

    cd lab-server
    node seed-market.mjs > seed-market.sql        # data/sample_market.csv 를 읽는다
    npx wrangler d1 execute bonghwa-lab --remote --file=seed-market.sql

진짜 자료를 옮길 때는 `data/sample_market.csv` 자리에 시트에서 내려받은 CSV 를 두면 됩니다.
칸 이름은 `docs/market-sheet-spec.md` 와 같아야 합니다.
