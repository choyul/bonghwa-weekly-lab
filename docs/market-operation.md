# 장터 운영 안내 (담당자용)

**장터는 스스로 정리됩니다.** 담당자가 매일 볼 필요가 없습니다.
평소에 하실 일은 없고, **한 달에 한 번 5분**만 보시면 됩니다.

승인 화면 주소: **`market-admin.html`** — 열람 코드는 보조사업 화면과 같습니다.

---

## 1. 저절로 돌아가는 것들

| 언제 | 무슨 일이 | 담당자 |
|---|---|---|
| 주민이 판매자 등록 | **바로 됩니다** (전화 확인 없음) | 없음 |
| 처음 올린 글 | 하루 뒤에 뜹니다. 새로 오신 분은 하루 한 건 | 없음 |
| 이웃 둘이 신고 | 글이 **확인중**이 되고 주문이 잠깁니다 | 없음 |
| 게시자가 글을 고침 | **신고가 저절로 풀리고** 다시 올라갑니다 | 없음 |
| 사흘 동안 답 없음 | 글이 **저절로 내려갑니다** | 없음 |
| 사진 신고 한 건 | **사진만 즉시 가려집니다** (글은 그대로) | 없음 |
| 연락처·계좌 신고 한 건 | 그 칸만 즉시 가려집니다 | 없음 |
| 마감일시가 지남 | 마감 | 없음 |
| 수령일 + 이레 | 종료 + 판매자 실적 한 건 | 없음 |
| 종료 + 한 달 | **사진이 지워집니다** | 없음 |
| 종료 + 세 달 | 글 내용이 지워집니다 | 없음 |
| 활동 없음 90일 | **연락처가 지워집니다** | 없음 |

이 모두를 **매일 새벽 4시**에 도는 청소가 합니다.

## 2. 신고가 무기가 되지 않게

- 같은 기기는 같은 글에 **한 번만**, 하루 **세 건**까지
- 게시자가 [고칠 것 없습니다]를 누르면 바로 올라옵니다
- 그 뒤 **이레 동안 같은 신고가 없으면 그 신고는 무고**로 봅니다
- **무고가 세 번 쌓인 기기의 신고는 세지 않습니다.** 알려주지 않습니다 —
  알려주면 기기를 바꿔서 또 합니다

## 3. 거듭 걸리면

| | 글 | 판매자 |
|---|---|---|
| 1번 가려짐 | 고치면 바로 복귀 | — |
| 2번 | 복귀에 하루 걸림 | **이레 쉼** (저절로 풀림) |
| 3번 | **글이 내려감** | **멈춤** (여기만 사람이 필요) |

## 4. 한 달에 한 번, 5분 동안 하실 일

`market-admin.html` 을 열고 **[손볼 것만 보기]** 에 걸린 것만 봅니다.

1. **[판매자]** 탭 — **멈춤**인 분이 억울하지 않은지 봅니다.
   신고가 세 번 쌓여 저절로 멈춘 분들입니다. 문제가 없으면 [멈춤 풀기].
   *'쉬는 중'은 손대지 않으셔도 이레 뒤 저절로 풀립니다.*
2. **[글]** 탭 — **확인중**인 글은 그냥 두십시오. 사흘 뒤 저절로 정리됩니다.
   **범죄·아동 관련처럼 기다릴 수 없는 것만** [아주 지우기]를 누르십시오.

그게 전부입니다.

## 5. 전화가 오면

**"수정키를 잃어버렸습니다"** → [판매자] 탭에서 그분을 찾아
[수정키 재발급]을 누르고 나온 값을 **전화로 불러** 드립니다.
누른 순간 예전 키는 못 쓰게 되니, 본인이 맞는지 확인한 뒤에만 누르십시오.

**"제 글이 안 보입니다"** → 처음 올린 글은 하루 뒤에 뜹니다.
그 뒤에도 안 보이면 확인중이거나 멈춤입니다. [글] 탭에서 찾아보십시오.

## 6. 사진

- 판매자가 **최대 석 장**까지 올립니다.
- 큰 사진은 **휴대폰에서 저절로 줄여** 보냅니다(긴 변 1280px, 보통 100~200KB).
  이때 사진에 든 **위치정보도 함께 지워집니다.**
- 한 장이 400KB를 넘으면 서버가 받지 않습니다.
- **거래가 끝나고 한 달이 지나면 사진은 저절로 지워집니다.**
  글을 지우면 사진도 그 자리에서 함께 지워집니다.
- 사진은 **주소를 직접 열어 볼 수 없습니다.** 워커를 거치므로
  가리거나 지우면 **그 자리에서** 안 보이게 됩니다.

### 사진을 어디에 두는가

지금은 **Workers KV** 에 둡니다. R2 가 더 맞는 그릇이지만
계정에 결제수단을 등록해야 켜지기 때문에, 그것 때문에 사진 기능이
멈춰 서지 않도록 KV 로 시작했습니다.

| | 지금 (KV) | 나중에 (R2) |
|---|---|---|
| 무료 저장 | 1GB — 사진 약 **6,900장** | 10GB |
| 하루 올리기 | 1,000장 | 사실상 무제한 |
| 덤 | 넣을 때 **180일 시한**을 함께 걸어 둔다 | — |

한 해 3,000장을 올려도 450MB 정도이고, 종료 30일이면 저절로 지워지므로
1GB에 닿을 일이 없습니다. KV 의 시한은 **새벽 청소가 어느 날 죽더라도
사진은 저 혼자 사라지게** 하는 뒷그물입니다.

R2 로 옮기시려면 대시보드에서 R2 를 켜고,

    npx wrangler r2 bucket create bonghwa-lab-photos

그다음 `lab-server/wrangler.jsonc` 의 `r2_buckets` 주석 한 줄만 푸시면 됩니다.
코드는 **R2 가 있으면 R2 를 먼저 씁니다.** 고칠 곳이 없습니다.
(옮기기 전에 올라온 사진은 KV 에 남으니, 옮기실 거면 이른 편이 좋습니다.)

## 7. 개인정보

- 판매자의 **실명과 휴대폰**은 `market-admin.html` 에서만 보입니다.
  장터 화면에는 어떤 경우에도 나가지 않습니다.
- 신고한 사람이 누구인지는 **아무에게도, 담당자에게도** 보이지 않습니다.
- 90일 활동이 없으면 연락처는 **저절로** 지워집니다. 손대실 것 없습니다.

## 8. 이것만은 사람이 해야 합니다

자동으로 할 수 없는 것이 셋 있습니다. 그래서 **비상 연락처 한 개**는
화면에 반드시 남겨 두십시오 — 없으면 게시판 운영자의 임시조치 의무를
다했다고 말할 수 없습니다.

1. 멈춘 분의 멈춤 풀기
2. 범죄·아동 관련 긴급 삭제
3. 법적 요청 대응

## 9. 숫자를 바꾸려면

신고 2건, 72시간, 이레, 90일, 사진 3장·400KB 같은 값은
`lab-server/src/worker.js` **맨 위 상수 한 곳**에 모여 있습니다.
바꾼 뒤에는 `cd lab-server && node scenario.mjs` 로 173가지를 다시 돌려 보십시오.
